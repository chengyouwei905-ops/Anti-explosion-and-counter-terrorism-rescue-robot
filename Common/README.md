# Common — 通用工具

## 放什么

- 与硬件**无关**的通用代码：环形缓冲、类型定义、返回码、CRC、滤波器、日志宏
- 理论上可以直接拷到 PC 上编译测试（不依赖 HAL）

## 铁律

- **只依赖 C 标准库**，不 include 项目内任何其它模块
- 所有层都可以用它（它是依赖树的最底层）

## 当前内容

| 文件 | 内容 |
| --- | --- |
| `common_def.h` | `ret_code_t` 返回码、`ARRAY_SIZE`、小端读写 `le_i16_get` / `le_i16_put` |
| `ring_buffer.c/.h` | 单生产者-单消费者环形缓冲，容量取 2 的幂 |
