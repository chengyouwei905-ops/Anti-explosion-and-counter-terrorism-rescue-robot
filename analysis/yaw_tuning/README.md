# 角度环实车调参结果

已使用工程现有 VS Code 配置对应的 OpenOCD/CMSIS-DAP 无线烧录链路，逐轮修改参数、编译、烧录，并仅通过视觉串口 UART7/COM9 接收数据。没有依赖电脑向主控发送串口命令。

最终采用：

```c
#define CHASSIS_YAW_KP_RAD 4.0f
#define CHASSIS_YAW_KI 0.0f
#define CHASSIS_YAW_KD 90.0f
#define CHASSIS_MAX_OMEGA_RADPS 1.2f
```

参数位于 `App/Src/app_chassis_closeloop.c`，已编译、烧录并通过校验。
当前 `PID_Update()` 使用 `Kd * (Error0 - Error1)`，不除以 dt，**Kd=90 适用于本次约10ms控制周期**，相当于该周期下约0.9的连续微分系数。不要把90直接用于已除dt的另一种PID实现。
本次没有启用积分，也没有更改通用 PID 算法。

## 测量方法

- 保留用户 main 中的0°/90°目标切换方式，10秒切换一次。试验执行两次往返后自动停止；发生角度越界、速度异常、IMU校准失败或读取超时也停止。
- 第一轮从低速开始，确认反馈方向正确，再测试1.2rad/s输出限幅。
- 约50Hz单向输出时间、目标角、IMU连续yaw、Z轴角速度、最终角速度命令、发送返回值和IMU错误计数。
- 遥测角度分辨率为0.001rad（约0.057°），时间分辨率约20ms。
- 超调取超出目标方向的最大角度；稳定时间取此后持续处于±2°范围的首个时刻；保持误差取每个10秒阶段最后1秒的平均误差。
- 下表的结果是IMU反馈相对目标的误差，未用独立角度基准校验绝对航向精度，也未覆盖不同地面、载荷、电池电压和外力扰动。

| 09 | 4 | 0 | 90 | 1.2 | 0.74° | 1.06s | 0.12° | 改为15°小阶跃，四次有效转角 |

最终组合在两轮独立90°试验中完成8个有效阶跃：

- 最大超调约1.38°；进入并保持±2°约1.42～2.36秒。
- 最后1秒平均误差最大约1.38°，没有发现持续往复摆动。
- 15°小阶跃稳定时间约0.72～1.06秒，最大超调约0.74°。
- 最终验证轮次未记录到IMU读取错误、非零电机发送返回值或超过100ms的遥测缺口。

选择此组参数侧重低超调与重复稳定性。上述范围是本轮实测结果，不是所有工况的保证。
角速度输出限幅也属于本次验证条件；从1.2rad/s提高限幅时需要复测。motion圆弧的规划角速度和纠偏余量同样受此限幅影响。

## 工程最终状态

- 临时试验模块、参数头文件和单向遥测已从正式源代码移除。
- `Core/Src/main.c` 的 `CHASSIS_YAW_STEP_TEST` 默认为0：关闭自动转角，恢复motion和closeloop按节拍依次更新；空闲时保持初始化航向。
- 将该宏改为1再编译烧录，可恢复用户原有每10秒切换0°/90°的调试行为。此模式会持续往返，请在适合的场地使用。
- 没有增加 `s_target_valid` 等目标有效性门控。
- 通用PID未改变；运动仿真测试已更新为本次增益及限幅预期并通过。最终固件已烧录校验。
