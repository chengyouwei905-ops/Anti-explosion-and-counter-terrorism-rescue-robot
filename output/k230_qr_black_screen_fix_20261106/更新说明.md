# 扫码黑屏修复

基于上一版“11点版扫码只读任务码、轮廓24点”完整文件。
本次只修改guanggongsai/competition_main.py，其余56个程序/参数/模型/标定文件保持字节一致。

## 原因及修改

扫码不再进行坐标平均，因此manager.average为None。主循环每秒的QR状态日志仍访问
len(manager.average.samples)，等待扫码超过1秒时会抛出AttributeError。
随后原有退出清理发送TOTALSTOP、关闭显示，造成黑屏与底盘停止。

修复将这条日志改为输出decode_only模式与请求SEQ，不再访问位置平均对象。
未修改主动总停、异常退出清理、UART协议、扫码判定、参数或MCU。

## 更新

MCU已烧录上一版STM32H723VGT6test_qr_decode.elf时无需重新烧录。
K230只需覆盖本包guanggongsai/competition_main.py，然后重启脚本。
也可解压完整ZIP，使用其中完整guanggongsai目录。

## 验证

python -B tests/test_k230_qr_black_screen.py：30项测试通过。
新增实际main主循环回归：等待扫码超过1秒、1.75秒后读码成功并继续预览、0.3秒内读码成功后空闲预览。
修复前复现AttributeError: 'NoneType' object has no attribute 'samples'，修复后上述路径正常运行。
参数保持MAX_POINTS_PER_RING=24、原LAB/ROI和后续5帧精定位设置。
