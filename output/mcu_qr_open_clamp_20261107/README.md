# 扫码成功后边走边张开夹爪

烧录 `STM32H723VGT6test_qr_open_clamp.elf`，K230无需更新。

收到有效QR成功回包后，仅发送一次ID5夹爪张开指令：位置使用当前CLAMP_OPEN_POSITION（437），运动时间1000ms。
串口接受提交后，同轮task_poll启动MOVE2；不等待这1000ms动作完成，也不附加500ms停稳等待。机械臂ID1/2/3/4不因这次张爪额外移动。

串口BUSY每20ms重试提交，最长1秒；提交失败仍按机械臂故障处理。总停优先取消尚未提交的张爪。重复/晚到扫码回包不会重复张爪。

该分支仅在QR成功后执行；救援携带人质时保持夹紧。保留常规动作1000ms、上电指定动作5000ms、打靶Z仅诊断及下一MOVE扣除已走名义位移的逻辑。现场姿态及参考点沿用当前工程。

6组定向测试及固件编译通过，覆盖真实ID5协议帧、无动作等待、BUSY/错误/超时、总停、重复回包、tick回绕和全程模拟。另保留16组打靶高度与36组MOVE交接回归。未上板或实车验证。
