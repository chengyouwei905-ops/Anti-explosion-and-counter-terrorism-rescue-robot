# 常规机械臂运动1000ms

> 此固件仍包含旧的MOVE补偿方向，已被 `../mcu_move_deduction_20261107/STM32H723VGT6test_move_deduction.elf` 替代；新版保留1000ms动作和5000ms上电例外。以下为旧版记录。

烧录 `STM32H723VGT6test_arm_1000ms.elf`，K230无需更新。

- 观察、夹取、放置、抬臂、yaw分段转动、收臂及夹爪：每条运动指令1000ms。
- 默认初始化关节动作和默认move_to：1000ms。
- 每段仍保留100ms发送余量和500ms停稳等待，因此状态机等待1600ms。
- 指定上电例外：位置{300,595,907,630,855}、运动5000ms、动作前延时3000ms、动作后延时5000ms。

上电数组按原始舵机位置0..1000，通过现有app_roboarm_positions_it发送。原move_direct接口接收弧度，不适合这些位置值；此次已修正接口，位置值保持原样。

保留上一版作业后不返回起点、到第三位的补偿并入下一MOVE、视觉纠偏保留、补偿取用一次及旧视觉回包拒绝逻辑。视觉settle_ms、激光时长和动作超时参数保持当前值。

4组定向测试和固件编译通过，包含真实运动帧时长、分段等待/BUSY/取消/错误/tick回绕、上电5000ms帧，以及36组作业到下一MOVE衔接。未上板或实车验证。
