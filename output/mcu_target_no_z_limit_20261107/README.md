# 取消打靶Z范围拦截

烧录 `STM32H723VGT6test_target_no_z_limit.elf`，K230无需更新。

打靶定位0x31不再因为换算后的Z超出参考高度±50mm而拒绝成功回包。Z仍参与完整坐标换算，高度误差及超差标志仍可查看，但不阻止X/Y纠偏或激光照射。

保留X/Y范围、有限坐标、协议/SEQ/slot/采样数/散布、纠偏限幅和航向检查。排爆和救援的Z范围规则保持原样。

当前现场参考点、姿态、扫描窗口、速度和上电位置值保持原样。常规机械臂1000ms、上电指定动作5000ms、作业后不返回起点及下一MOVE减去已走名义位移的逻辑均保留。

4组定向测试及固件编译通过。其中16组使用真实生产配置，覆盖Z误差±60/±200mm、有无平移纠偏及tick回绕，确认能进入照射并继续MOVE13；另有36组作业至下一MOVE交接。未上板或实车验证。
