# 下一MOVE扣减方向修正版

请烧录 `STM32H723VGT6test_move_deduction.elf`，替代前两版mcu_fast_exit和mcu_arm_1000ms固件。K230无需更新。

正确公式：下一MOVE首段距离 = 原配置距离 - 当前已走的名义扫描位移。

- 排爆：底盘到第二位放桶，MOVE12固定减150mm，与选中哪个爆炸物无关。
- 打靶：在第1/2/3位完成后，MOVE13分别减0/150/300mm。
- 救援：在第1/2/3位完成后，MOVE16分别减0/150/300mm。

不返回扫描起点，不额外移动到第三位。视觉纠偏保留，不参与这次扣减。原路线参数保持只读，扣减只作用于本次启动的副本，防止重复扣减；原横移和组内连续转弯保留。

定位、作业、关激光和收臂完成后才移交下一MOVE。扣减取用一次；总停使其失效；移动期间旧视觉回包被忽略，下一作业区重新发起扫描。

常规机械臂/夹爪1000ms，上电指定位置5000ms及原位置值保留。每段发送和停稳余量保持当前值。

7组定向测试及固件编译通过。包含36组作业到下一MOVE交接、不同命中位置下原定终点一致、6组扣减后距离非正时拒绝启动、视觉异常重试、QR、旧回包、一次取用、总停/重启及tick回绕。未实车或上板验证。
